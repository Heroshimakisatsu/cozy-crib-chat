# Home Match AI

No data base just Create a UI with mock data only and this is for Android and IOS Phones, make sure the screen orientation is compatible with MOBILE PHONES:
Design a complete, minimalist, and responsive housing Mpobile device app interface for house hunters, utilizing a warm, home-inspired color palette with soft beige backgrounds, creamy off-white UI elements, terracotta primary action buttons, and dark green accents for trust. The application includes a combined registration and authentication page with fields for contact information, email, location, and a password setup. The landing page features a prominent, centered text input for AI prompting, supported by example prompt cards. Upon execution, the results page displays a short AI response along with a list of landlord cards summarizing the search results. Each card, when selected, expands to detail house conditions, specific location, and provides contact fields and a direct chat button.
